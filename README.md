# Welcome to `flaspland`

<img src="https://i.imgur.com/9cNtWjs.gif" width="480" alt="Flatland animation">

Flatland is a [railway scheduling challenge](https://flatland.aicrowd.com/intro.html) hosted by AICrowd that seeks to solve the problem of multi-agent pathfinding for trains in large railway networks.  Since Flatland is written in Python, `flaspland` was created to bridge the gap between Flatland and ASP encodings.
